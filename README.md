# 拼图 · AI 局部修补

一个单文件、纯前端的网页小工具：框选图片中需要修改的区域，交给 ChatGPT / Gemini 等 AI 重绘，再把结果贴回原图，实现**局部修补**，避免整图重新生成。

## 功能

- 框选要修改的区域（可带边距），一键复制并跳转 ChatGPT / Gemini
- 从剪贴板或文件读取 AI 生成的结果图，贴回选区
- 贴回时支持拉伸 / 等比覆盖 / 等比包含、像素级偏移、边缘羽化、吸附对齐
- 修改前后对比、撤销、可反复修补多处
- 以原始分辨率导出完整拼合图或补丁 PNG
- 支持触屏 / Apple Pencil 与键盘快捷键（按 `?` 查看说明）

## 使用

直接用浏览器打开 `index.html` 即可，无需安装，图片只在本地处理。
