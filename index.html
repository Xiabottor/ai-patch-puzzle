使用说明

👆 触控 / Apple Pencil

单指拖框选；拖框内移动，拖角/边调整 ✎ 模式用笔框选，单指拖动平移（检测到 Pencil 自动开启） 双指捏合缩放、拖动平移 双指轻点撤销 三指轻点重做 单指双击适应窗口 ↔ 放大到选区 长按再拖本次拖动不吸附 选区 / 补丁切换框内拖动移动的对象，默认移动选区 ▢ 隐藏边框隐藏选区边框，拖动改为平移 👁 对比按住查看修改前 竖屏点面板顶部可收起 / 展开

⌨ 键盘（妙控键盘 / 电脑）

⌘V粘贴原图或 AI 结果 ⌘C复制选区（含边距） ⌘Z 撤销（⇧ 重做） ⌘S导出完整拼合图 C V A切换 框选 / 贴回 / 调整 F 1 Z适应 / 100% / 缩放到选区 方向键微调补丁或选区（⇧ ×10） B按住看修改前 H隐藏 / 显示选区边框 ␣按住拖动平移 ⏎ / Esc应用 / 清除结果

流程：① 载入原图 → 框选（AI 爱出方图就锁 1:1，可加边距）→ 复制并打开 Gemini / ChatGPT → ② 在 AI 里长按图片「拷贝」，回来粘贴结果 → ③ 羽化、微调、应用（可多处），最后导出。
